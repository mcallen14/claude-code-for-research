# Claude Code for Research

A practical guide to using [Claude Code](https://code.claude.com) well for scientific computing, data analysis, modeling, and research software development — for anyone from someone who's barely used a coding agent to someone ready for more advanced agentic workflows.

**➡️ [Read the full guide on the Wiki](../../wiki)**

## Try it yourself

The Practice Walkthrough pairs with a small, real, standalone repo built for exactly this: **[claude-example-camels](https://github.com/mcallen14/claude-example-camels)** — calibrate a real hydrologic model to real streamflow data, with a few issues deliberately built in to practice debugging alongside Claude Code.
